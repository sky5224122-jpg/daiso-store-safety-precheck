# 매장 안전보건관리체계 사전지원 평가 앱

ISO 45001 심사 · 중대재해처벌법 대응을 위한 매장 사전지원 방문 평가 체크리스트 웹앱입니다.

기준: `26년 매장 안전보건관리체(ISO45001) 준비 사항_26_0821.pptx` 19~22페이지 지원 체계 및 평가 항목

## 구성

- **문서 영역** (10항목) — 위험성평가서, 관리감독자 업무수행, 비상대응훈련, 산재조사표, TBM/교육일지, 게시자료, 행정서류
- **현장 영역** (12항목) — 비상구, 대피, 소방, 창고, 자동문, 보호구, 계절안전
- **인터뷰 영역** (9항목) — 점장 6문항, 파트장 3문항

각 항목을 A~D 등급으로 평가하면 영역별 등급과 최종 등급이 자동 계산됩니다.
등급은 점수로 환산해(A=4점 · B=3점 · C=2점 · D=1점) **전체 항목(또는 영역 내 항목)의 평균 점수**로 등급을 산정합니다. 미해당(N/A) 처리한 항목은 평균 계산에서 제외됩니다.

| 등급 | 의미 | 후속 조치 |
| --- | --- | --- |
| A | 양호 | 후속 방문 불필요 · 분기 사후 확인만 진행 |
| B | 일부 결손 | 보강자료 1회 제공 · 재점검 후 A등급 전환 |
| C | 보강 필요 | 후속 방문 1~2회 · 핵심 보강자료 및 현장 코칭 |
| D | 집중 지원 | 집중 지원팀 편성 · 후속 방문 2~3회 · 주간 점검 |

## 사용 방법

1. 방문일 · 평가자(강동현/유준하/서유림/윤정인) · 매장명을 입력합니다.
2. 문서 · 현장 · 인터뷰 32개 항목을 A~D로 평가합니다. (해당 없음 항목은 N/A 선택)
3. 최종 등급을 확인하고 특이사항을 메모합니다.
4. **결과 저장**(이 기기 브라우저에 누적) / **결과 텍스트 복사**(메일·메신저 공유용) / **인쇄·PDF 저장** 중 선택합니다.

데이터는 별도 서버 없이 브라우저 로컬저장소(localStorage)에 저장됩니다 — 기기별로 독립적으로 보관되며, 외부로 전송되지 않습니다.

## 기술 스택

순수 HTML/CSS/JavaScript (빌드 도구, 백엔드 없음) — GitHub Pages로 바로 호스팅됩니다.
