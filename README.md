# 매장 안전보건관리체계 사전지원 평가 앱

ISO 45001 심사 · 중대재해처벌법 대응을 위한 매장 사전지원 방문 평가 체크리스트 웹앱입니다.

기준: `26년 매장 안전보건관리체(ISO45001) 준비 사항_26_0821.pptx` 19~22페이지 지원 체계 및 평가 항목

## 구성

- **문서 영역** (10항목) — 위험성평가서, 관리감독자 업무수행, 비상대응훈련, 산재조사표, TBM/교육일지, 게시자료, 행정서류
- **현장 영역** (13항목) — 비상구, 대피, 소방, 창고, 자동문, 보호구, 계절안전, 기타(체크리스트에 없는 사항 자유 기록)
- **인터뷰 영역** (8항목) — 점장 8문항

각 항목을 A~D 등급으로 평가하면 영역별 등급과 최종 등급이 자동 계산됩니다.
등급은 점수로 환산해(A=4점 · B=3점 · C=2점 · D=1점) **전체 항목(또는 영역 내 항목)의 평균 점수**로 등급을 산정합니다. 미해당(N/A) 처리한 항목은 평균 계산에서 제외됩니다.

| 등급 | 의미 | 후속 조치 |
| --- | --- | --- |
| A | 양호 | 후속 방문 불필요 · 분기 사후 확인만 진행 |
| B | 일부 결손 | 보강자료 1회 제공 · 재점검 후 A등급 전환 |
| C | 보강 필요 | 후속 방문 1~2회 · 핵심 보강자료 및 현장 코칭 |
| D | 집중 지원 | 집중 지원팀 편성 · 후속 방문 2~3회 · 주간 점검 |

## 사용 방법

1. 방문일 · 평가자(강동현/유준하/서유림/윤정인) · 매장명을 입력합니다.
2. 문서 · 현장 · 인터뷰 31개 항목을 A~D로 평가합니다. (해당 없음 항목은 N/A 선택, 현장 영역의 "기타"는 등급 없이 메모만 남겨도 됩니다)
3. 최종 등급을 확인하고 특이사항을 메모합니다.
4. 필요하면 각 항목 아래 **"📷 사진 촬영 · 첨부"** 버튼으로 현장 사진을 붙일 수 있습니다 (촬영 즉시 자동 압축되며, × 버튼으로 개별 삭제 가능).
5. **결과 저장**(이 기기 + 공유 저장소) / **결과 텍스트 복사**(메일·메신저 공유용) / **인쇄·PDF 저장** 중 선택합니다.

### 사진 용량 관리

- 사진은 촬영 즉시 자동으로 리사이즈·압축되어 장당 약 180KB 이하로 저장됩니다 (화질이 좋아도 자동으로 더 낮춰 재압축).
- 항목 하나당 최대 **3장**까지만 첨부할 수 있습니다.
- 화면 하단(임시저장 버튼 아래)에 **"이 기기 저장 용량 사용"** 표시가 있어 현재 사용량을 항상 확인할 수 있습니다.
- 저장 공간이 부족해질 것 같으면 저장 전에 미리 차단하고 안내하며(조용한 실패 방지), **"오래된 사진 정리"** 버튼으로 가장 오래된 기록부터 사진만 삭제해 공간을 확보할 수 있습니다 (등급·메모 등 텍스트 결과는 그대로 유지됩니다).

## 결과 취합 (공유 저장소)

4명의 평가자가 각자 기기에서 저장한 결과를 한 곳에서 모아 보려면 [`google-apps-script/README.md`](./google-apps-script/README.md) 안내에 따라 Google Sheets + Apps Script를 5~10분 정도 들여 연결하세요.

- 연결 전: 결과가 각자 브라우저의 로컬저장소(localStorage)에만 저장됩니다 — 기기별로 독립 보관, 다른 사람과 자동으로 합쳐지지 않습니다.
- 연결 후: "결과 저장" 시 이 기기 + 공유 스프레드시트에 동시 저장됩니다. **화면 하단 "매장 평가 통계"는 누구나 볼 수 있으며**, 공유 저장소에서 4명 전체 결과를 실시간으로 불러와 집계합니다.
- **사진은 용량 제한(구글시트 셀 5만자)으로 공유 저장소에는 전송되지 않고, 촬영·첨부한 이 기기에만 저장됩니다.** 다른 사람과 공유하려면 인쇄(PDF 저장)하거나 사진을 별도로 전달하세요.
- 공유 저장소에 연결된 뒤에도 "저장된 평가 이력" 표는 이 기기에 저장된 기록만 보여줍니다 — 전체 집계는 통계 카드에서 확인하세요.
- 원본 텍스트 데이터는 연결된 구글 스프레드시트를 직접 열어서도 언제든 확인·정렬·필터링할 수 있습니다.

## 기술 스택

순수 HTML/CSS/JavaScript (빌드 도구 없음) — GitHub Pages로 프런트엔드를 호스팅하고, 결과 취합은 Google Apps Script 웹앱(무료)을 백엔드로 사용합니다.
