# 공유 저장소 설치 방법 (Google Sheets + Apps Script)

이 설정을 마치면 강동현 · 유준하 · 서유림 · 윤정인 4명이 각자 기기에서 저장한 평가 결과가
**하나의 구글 스프레드시트**에 자동으로 모입니다. 5~10분이면 끝나며, 비용은 들지 않습니다.

## 1. 구글 스프레드시트 새로 만들기

1. [sheets.google.com](https://sheets.google.com) 접속 → 빈 스프레드시트 새로 만들기
2. 이름을 `매장_사전지원_평가_결과` 등으로 지정

## 2. Apps Script 코드 붙여넣기

1. 방금 만든 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 기본으로 열려있는 `Code.gs` 내용을 전부 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 그대로 붙여넣기
3. 저장 (Ctrl+S)

## 3. 웹앱으로 배포

1. Apps Script 편집기 우측 상단 **배포 → 새 배포**
2. 유형 선택(톱니바퀴)에서 **웹 앱** 선택
3. **실행 계정: 나(본인 계정)** / **액세스 권한: 전체(익명 사용자 포함)** 로 설정 — 평가자들이 로그인 없이 결과를 전송해야 하므로 반드시 "전체"로 설정
4. **배포** 클릭 → 처음 배포 시 구글이 권한 승인을 요청함 → 본인 계정으로 **허용** 진행
   - "확인되지 않은 앱" 경고가 뜨면 **고급 → (프로젝트명)(으)로 이동 → 허용** 클릭 (본인이 만든 스크립트이므로 안전함)
5. 배포 완료 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec` 형태)을 복사

## 4. 앱에 연결

1. 이 저장소의 `data.js` 파일을 열기
2. `SYNC_CONFIG.url` 값에 3번에서 복사한 주소를 붙여넣기

```js
const SYNC_CONFIG = {
  url: "https://script.google.com/macros/s/여기에_배포된_주소/exec",
  secret: "daiso-shms-2026",
};
```

3. 저장 후 GitHub에 커밋·푸시하면 반영됩니다.

## 참고

- `SYNC_CONFIG.secret` 값은 `Code.gs`의 `SHARED_SECRET`과 반드시 동일해야 합니다. (완전한 보안은 아니고, URL을 모르는 제3자의 무분별한 기록 남용을 막는 최소 장치입니다)
- 코드를 수정한 뒤에는 Apps Script에서 **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전 → 배포** 를 다시 눌러야 반영됩니다. (웹앱 URL은 그대로 유지됨)
- 결과 원본 데이터는 스프레드시트에서 언제든 직접 열어 확인·정렬·필터링할 수 있습니다.
